# Multi-Orbit Propagation and Pass Prediction Tool

## Overview

A professional aerospace systems engineering project that performs:

- Live TLE ingestion
- Orbit propagation using SGP4
- Ground station pass prediction
- Eclipse detection
- Ground track visualization
- Orbit comparison (LEO, SSO, Molniya)

## Tech Stack

- Python
- Skyfield
- SGP4
- NumPy
- SciPy
- Plotly
- Streamlit
